The terms of the Game Guide, with a short definition of each. The site lists them alphabetically on the [Glossary page](#/glossary), built from this page.

> [!TIP]
> To add a term, copy an entry below and change it, anywhere on the page. Start with a `###` heading holding the term. Under it write the definition in a sentence or two, and put the details on the page named under See also. The lines "Category:", "Also called:" and "See also:" are optional. Reuse a category already on this page where one fits; the site groups the terms by it. The site sorts the terms, so the order here does not matter.

### Renown

*Category:* Character

*Also called:* Renown level

An online only progression level earned through various activities. It effects: Health, Magika, Firmament, Sigils and Loot.

*See also:* [[Renown]]
