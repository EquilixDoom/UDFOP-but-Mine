The Site Guide is the help section of UDOP. It explains how to write, fix and review Game Guide pages, and how to use the site. These pages are about the project itself. The pages about the game are in the [Game Guide](#/guide). New here? Start with [[site:How to write a guide page]].

## Writing a page

- [[site:How to write a guide page]] – A step-by-step walkthrough for adding a page to the Game Guide or fixing one, from your first fork to seeing it live.
- [[site:Formatting reference]] – Every kind of formatting a guide page can use, with the syntax to type and how it looks.
- [[site:Anatomy of a page]] – What each part of a guide page is, which part of your file makes it, and what the site adds on its own.
- [[site:Troubleshooting and FAQ]] – Fixes for the most common problems when writing a page, and what each page-check message means.

## Using the site

- [[site:Using the site]] – How to search, use the menus and Contents, change the look in Settings, and read the site on a phone.

## Looking after the Game Guide

- [[site:Reviewing a pull request]] – What to check when someone sends a guide page, how to give kind feedback, and how to merge it.
